# Music Producer Site

Projet de site web de production musicale proposant des packs de samples, presets, templates, tout pour réussir en tant que producteur de musique electronique.
Projet NextJS en Typescript, avec Shadcn et TailwindCSS.
Le site fait appels a l'API de Pexels pour les photos et Pixabay pour les extraits audio.

### Démo : [musicproducersite.vercel.app](https://musicproducersite.vercel.app/)

## Fonctionnalités

- Exploration de packs de samples et de presets
- Écoute d'extraits audio
- Interface design, user-friendly et responsive
- Médias dynamiques provenant de Pexels (images) et Pixabay (pistes audio)

## Stacks Utilisés

- **Framework :** NextJS / Typescript
- **Styling :** Tailwind CSS / Vanilla CSS
- **Design System :** Shadcn UI

## Installation & Démarrage local

Pour lancer localement le projet, suivez les étapes ci-dessous

**1. Clonez le repo**  
```bash
git clone [https://github.com/ton-pseudo/music-producer-site.git](https://github.com/ton-pseudo/music-producer-site.git)
cd music-producer-site
```  
2. Installez les dépendances
```bash
npm install
# ou yarn install / pnpm install
```  
3. Lancez le serveur de développement
```bash
npm run dev
```  
Ouvrez `http://localhost:3000` dans votre navigateur pour voir le résultat.
